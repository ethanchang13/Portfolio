Snowflake Designer Lab — Holiday Traditions

Our group submission for the Winter Holiday & Traditions Web Design Challenge — an interactive snowflake designer with cultural pattern stamps from 12 global winter traditions, a personal gallery, and PNG export.

Year: Senior Type: Interactive web app Role: Group / collaborative build
Visit the live site ↗ View on GitHub ↗

What it is

A canvas-based drawing tool where users design symmetrical snowflakes using brush tools with automatic 4-fold, 6-fold, or 8-fold reflection. Cultural pattern stamps drawn from twelve global winter traditions can be dropped onto the canvas, and finished designs save to a personal gallery (LocalStorage) or export as PNG.

Cultural patterns featured

Indian (Diwali) rangoli circles · Scandinavian (Yule) Nordic snowflakes · Jewish (Hanukkah) Star of David · Chinese (Lunar New Year) fortune coins · Japanese (Shogatsu) cherry blossoms · Mexican (Las Posadas) poinsettia flowers · German (Weihnachten) traditional stars · Russian (Novy God) Matryoshka patterns · Celtic (Winter Solstice) triquetra knots · Persian (Yalda) pomegranate motifs · African (Kwanzaa) unity symbols · Native American four-directions.

Tech stack

  • React
  • TypeScript
  • Vue 3 (pattern library widget)
  • HTML5 Canvas
  • Tailwind CSS
  • Vite
  • LocalStorage API

Highlights

Real-time symmetry drawing

Every brush stroke is automatically reflected across 4, 6, or 8 axes, so users design one wedge and the snowflake builds itself.

Two frameworks, one product

The main app is React + TypeScript, with a Vue 3 pattern-library widget embedded inside it — integrating cleanly across framework boundaries was the standout technical challenge.

Persistent gallery

Saved snowflakes (with thumbnails), dark / light mode preference, and achievement tracking all persist in LocalStorage across visits.

Responsive + atmospheric

Mobile-friendly touch controls, glassmorphism UI, and an animated snowfall background.

What I learned

  • Real Git collaboration on a shared repo — branches, PRs, and merge resolution under deadline pressure.
  • Integrating two component frameworks (React and Vue) in one deployable app.
  • Designing for cultural sensitivity — picking patterns and labelling them respectfully was a deliberate part of the build, not an afterthought.
  • Shipping a real product with a team is fundamentally different from shipping one alone.
