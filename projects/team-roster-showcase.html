Team Roster Showcase

A multi-page team-roster site — home, about, and a JavaScript-driven card-based roster — built to practice card-grid layout, multi-page navigation, and writing code that's actually documented.

Year: Junior Type: Multi-page roster site Role: Solo build
Visit the live site ↗ View on GitHub ↗

What it is

A small three-page site for showcasing a team — a landing page, an about page, and a roster page that renders each team member as a styled card. JavaScript drives the roster cards so adding, removing, or reordering a team member is a data change, not a markup change.

Tech stack

  • HTML5
  • CSS3
  • Vanilla JavaScript
  • Card-grid layout
  • GitHub Pages

Highlights

Card-grid roster

Each team member renders as a card in a responsive grid — one component pattern, repeated cleanly, no copy-pasted markup.

Multi-page navigation

Shared header and consistent visual identity across three pages so the site reads as one product instead of three separate files.

Actually-documented code

First project where I made myself write meaningful comments — what a function does, why a section exists, what data shape it expects. Re-reading the code months later, it paid off.

What I learned

  • Designing a repeatable card component instead of styling each entry by hand.
  • How to build a small multi-page site that feels coherent, not stitched together.
  • Why code comments are written for the future version of you, not for the assignment.
