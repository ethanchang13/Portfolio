The KeySpace Piano Studio

A full multi-page marketing site for a fictional piano studio - home, about, programs, and contact pages with a consistent visual identity and responsive layouts throughout.

Year: Senior Type: Client-Style Multi-page Site Stack: HTML · CSS · JavaScript
Visit the live site ↗ GitHub ↗

What it is

KeySpace Piano Studio is a fictional music school website built to feel like a real client deliverable. Four fully linked pages - home, about, programs, and contact - each carrying the same brand palette, type choices, and component patterns so the whole thing reads as one cohesive product rather than four separate pages stapled together.

Features

  • Four-page site with consistent global navigation and footer.
  • Custom brand palette and typography applied site-wide.
  • Programs page detailing lesson tiers and pricing.
  • Contact page with a styled inquiry form.
  • Fully responsive across mobile and desktop breakpoints.

Tech stack

  • HTML5
  • CSS3 (custom properties, flexbox, grid)
  • Vanilla JavaScript

Highlights

Brand ownership

Choosing a palette, picking type pairings, and writing the voice for every page - then holding those decisions consistently across four separate HTML files - is a different challenge than styling a single page. KeySpace was the first project where I felt like a designer, not just a coder.

Information architecture

Deciding what lives on which page, how the nav communicates the hierarchy, and how a visitor moves from curiosity to inquiry was a real planning exercise before a single line of markup was written.

Component consistency

Building the same card, button, and section styles once and reusing them across every page meant thinking in systems rather than one-offs. That mental shift carried into every project after this one.

What I learned

  • How to define and maintain a visual brand across multiple pages.
  • Multi-page information architecture and navigation design.
  • Building reusable component patterns from scratch.
  • Contact-page UX - form layout, labels, and accessible inputs.
  • The difference between "looks fine on one page" and "feels like a real product."
