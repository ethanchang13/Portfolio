Puppies — Bootstrap Image Gallery

A responsive puppy photo gallery built with Bootstrap's grid system — the first time I thought seriously about how a layout breaks at different screen sizes.

Year: Sophomore Type: Responsive image gallery Built in: CodeSandbox
Visit the live site ↗ View on CodeSandbox ↗

What it is

A photo gallery page filled with puppy images, arranged in a responsive grid using Bootstrap 5. At wide viewports the images sit in a multi-column grid; at smaller sizes the columns collapse so no image gets squished. Every image has proper alt text — the first time accessibility was a deliberate part of the build, not an afterthought.

Tech stack

  • HTML5
  • Bootstrap 5
  • CodeSandbox

Highlights

Image-heavy responsive grid

Arranged images across multiple columns with Bootstrap's grid so the gallery adapts cleanly from desktop to phone without any custom media queries.

Alt text on everything

Every image got a meaningful alt description — my first project where I thought about what a screen reader would say, not just what the page looks like.

Column nesting

Used nested Bootstrap columns to fit a featured large image alongside a grid of smaller thumbnails on the same row.

What I learned

  • How to arrange images in a grid that works at every screen size — not just "how it looks on my laptop."
  • Why alt text matters and how to write it usefully rather than leaving it blank.
  • What Bootstrap column nesting is for and how to use it without breaking the 12-column math.
