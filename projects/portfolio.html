Journey Map Portfolio (This Site)

An interactive map of my three years in the Web Design Pathway — drive a car around a hand-illustrated SVG world, visit themed buildings, and explore project data pulled from a JSON file with fetch.

Year: Senior · Capstone Type: Interactive portfolio Role: Solo design + build
Visit the live site ↗ View on GitHub ↗

What it is

Instead of a traditional scrolling portfolio, this site is a small drivable world. The car has real momentum, the sky has parallax depth, fireworks burst over a castle on a loop, and every building corresponds to a stop on my journey through the program. Project content is loaded from a single projects.json file so every card is data-driven.

Tech stack

  • HTML5
  • CSS3 (custom properties, animations)
  • Vanilla JavaScript (no frameworks)
  • SVG (hand-illustrated world)
  • Web Audio API
  • Fetch API + JSON
  • GitHub Pages

Highlights

A real, drivable car

Acceleration, friction, steering, and clamped world bounds — all hand-tuned to feel right rather than just move.

Parallax SVG world

Sky, mountains, and the main world all scroll at different rates as the car moves. The world is illustrated as inline SVG so every shape stays crisp at any zoom.

Web Audio engine + ambient sound

The car's engine is layered live: a deep sub-sine for the rumble plus a detuned sawtooth for harmonic growl, both modulated by current speed. Chimes, whooshes, splashes, rocket roars, and firework cracks are all synthesized from scratch, not sampled.

Keyboard and touch parity

Desktop visitors drive with WASD or arrows; mobile visitors get a drag-joystick and action button. Both control schemes drive the exact same physics.

Data-driven content

Every project card on the site is rendered from projects.json via fetch — there is no hard-coded project markup. Adding a project is a JSON edit, full stop.

Ambient life

Rockets launch from a pad on a timer, fireworks burst over the castle, hot-air balloons drift across the sky, and a flock of birds crosses in V formation. The world feels alive even when you're not driving.

What I learned

  • How to architect a moderately complex vanilla-JS app without reaching for a framework.
  • Game-feel: small things like easing, sound, and feedback completely change how an interaction reads.
  • Web Audio from scratch — synthesizing engines, chimes, and explosions instead of shipping audio files.
  • Building parity across input devices so the experience isn't second-class on mobile.
  • That a portfolio can be a piece of work in itself, not just a container for other work.
