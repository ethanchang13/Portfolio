My First Bootstrap Grid

The very first project — a multi-column responsive layout built entirely with Bootstrap's 12-column grid. The one where the grid finally clicked.

Year: Sophomore Type: Responsive layout Built in: CodeSandbox
Visit the live site ↗ View on CodeSandbox ↗

What it is

A multi-column layout page built from scratch using Bootstrap 5's grid system — rows, columns, and breakpoint utilities only. No custom CSS tricks, no flexbox workarounds. The goal was to understand the 12-column system by actually using it, not just reading about it.

Tech stack

  • HTML5
  • Bootstrap 5
  • CodeSandbox

Highlights

12-column grid from scratch

Built entirely from Bootstrap's row / col system — no copy-pasted templates, just the docs and trial and error until columns stacked where they were supposed to.

Responsive breakpoints

Used col-sm, col-md, and col-lg classes to control exactly how columns collapse at each screen size.

Fixed vs. fluid containers

Experimented with .container and .container-fluid to understand why they behave differently at wide viewports.

What I learned

  • How the 12-column grid system works — and why 12 divides so cleanly into halves, thirds, and quarters.
  • Watching columns automatically stack on mobile was the moment "responsive design" stopped being abstract.
  • The difference between a fixed-width container and a full-width one, and when you'd choose each.
