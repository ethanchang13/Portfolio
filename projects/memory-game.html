Memory Game

A themed multi-page card-matching game — splash page, instructions page, and the game page itself, all sharing one consistent design system.

Year: Junior Type: Browser game (multi-page) Role: Solo build
Visit the live site ↗ View on GitHub ↗

What it is

The classic flip-and-match memory game, but designed as a small suite of pages rather than a single screen. There's a landing page that introduces the game, an instructions page, and the actual game board — all sharing one visual identity so they feel like one product.

Tech stack

  • HTML5
  • CSS3 (per-page stylesheets)
  • Vanilla JavaScript
  • Themed image assets
  • GitHub Pages

Highlights

Multi-page architecture

Splash → instructions → game. Each page has one job, and the navigation between them feels intentional, not bolted on.

Card flip + match logic

Tracks revealed cards, compares pairs, locks the board between guesses, and resets non-matching cards cleanly so the game state never gets confused.

Themed image set

Custom card faces tied to the site's color palette so the game board feels like part of the world, not a generic grid of icons.

What I learned

  • How to architect a small site as a suite of pages with a shared identity.
  • Locking interaction during animation windows — the difference between a janky and a polished game feel.
  • Writing documentation comments while building, not after.
